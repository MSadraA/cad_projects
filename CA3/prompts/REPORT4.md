بخش اول: تکمیل تست‌های Forwarding پیشرفته (Batch 10)

این تست مسیرهای Forwarding مربوط به دستورات LW و SW و همچنین عملوندهای ترکیبی را ارزیابی می‌کند.

۱. شناسه تست: BATCH_10_ADV_FWD۲. هدف دقیق:

    ارزیابی Bypass داده از MEM/WB به هر دو پایه rs و rt در مصرف‌کننده.

بخش دوم: تکمیل تست‌های Load-Use Branch Stall (Batch 11)

این تست‌ها ایجاد وقفه (Stall) در دستورات انشعابی را در حالت‌هایی که وابستگی روی پایه rt یا به طور همزمان روی rs و rt وجود دارد بررسی می‌کنند.

۱. شناسه تست: BATCH_11_LD_USE_BR۲. هدف دقیق: اثبات اینکه واحد Hazard Detection برای تمام عملوندهای دستورات انشعاب متکی بر LW بلافصل، توقف صحیح ایجاد می‌کند.

۳. کد اسمبلی کامل (test_batch11_br.s):
Assembly

# Setup Memory: M[0]=10, M[4]=20
addi $t0, $zero, 10
sw   $t0, 0($zero)
addi $t1, $zero, 20
sw   $t1, 4($zero)
nop
nop

# T_LD_USE_BEQ_RT
addi $t2, $zero, 99
lw   $t2, 0($zero)      # New = 10
beq  $t0, $t2, pass1    # 10 == 10 (Should Stall, read 10 -> Taken)
nop
addi $s0, $zero, 1      # FAIL (If no stall, reads 99 -> Not Taken)
j end1
nop
pass1:
addi $s0, $zero, 2      # PASS
end1:
nop
nop

# T_LD_USE_BNE_RT
addi $t3, $zero, 99
lw   $t3, 4($zero)      # New = 20
bne  $t0, $t3, pass2    # 10 != 20 (Should Stall, read 20 -> Taken)
nop
addi $s1, $zero, 1      # FAIL (If no stall, reads 99 -> Also Taken! Wait.)
# Correction: If no stall, 10 != 99 (Taken). If stall, 10 != 20 (Taken). Both branch!
# We need to make the branch logic FAIL if it uses the OLD value.

اصلاح تست BNE:
باید مقدار قدیمی به گونه‌ای باشد که 10 != قدیمی False شود (یعنی قدیمی = 10 باشد) تا Branch نپرد، اما با داده جدید 10 != 20 True شود تا بپرد.
Assembly

# T_LD_USE_BNE_RT (Fixed)
addi $t3, $zero, 10     # Old = 10
lw   $t3, 4($zero)      # New = 20
bne  $t0, $t3, pass2    # 10 != 20 -> Taken (if stall). 10 != 10 -> Not Taken (if no stall).
nop
addi $s1, $zero, 1      # FAIL
j end2
nop
pass2:
addi $s1, $zero, 2      # PASS
end2:
nop
nop

# T_LD_USE_BEQ_BOTH
# Same register in rs and rt. Old = 1, New = 1.
# Actually, BEQ $t4, $t4 is ALWAYS equal, regardless of old or new. 
# We need two different registers loaded to test simultaneous hazard.
# We can't issue 2 LWs at once. But we can test if the stall holds long enough.
# Let's use old values that match, new values that don't match.
addi $t4, $zero, 5
addi $t5, $zero, 5
lw   $t4, 0($zero)      # Loads 10 (WB stage during BEQ ID)
lw   $t5, 4($zero)      # Loads 20 (MEM stage during BEQ ID)
beq  $t4, $t5, fail3    # Old: 5==5 (Taken). New: 10==20 (Not Taken - Correct if stalled).
nop
addi $s2, $zero, 2      # PASS (Fallthrough is correct)
j end3
nop
fail3:
addi $s2, $zero, 1      # FAIL (Branched due to reading old values)
end3:
halt
