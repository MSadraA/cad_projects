# اتصال سه جایگزین به پروژهٔ اول

سه ماژول زیر جایگزین نام‌به‌نام نسخه‌های CA1 هستند:

| ماژول | منبع جدید |
|---|---|
| `fcnn_fp16_adder` | `rtl/fcnn_fp16_adder.v` |
| `fcnn_fp16_multiplier` | `rtl/fcnn_fp16_multiplier.v` |
| `fcnn_ping_pong_buffer` | `integration/fcnn_ping_pong_buffer.v` |

از بستهٔ CA1 فقط همین سه فایل قدیمی را از فهرست کامپایل حذف کنید. سورس‌های جدید `rtl/actel/`، `rtl/common/` و سه فایل بالا را همراه دیگر RTLهای دست‌نخوردهٔ CA1 کامپایل کنید. کتابخانهٔ اصلی TA را هم‌زمان با `rtl/actel/modules.v` کامپایل نکنید؛ در غیر این صورت تعریف تکراری سلول‌ها خواهید داشت. `rtl/ping_pong_buffer.v` برای اتصال CA1 لازم نیست، ولی حضور آن با نام متفاوت تعارضی ایجاد نمی‌کند.

فرمان استاندارد برای نصب یک نسخهٔ ادغام‌شده در پوشه‌ای تازه:

```bash
python scripts/prepare_ca1_overlay.py --ca1-src PATH_TO_CA1_SRC --out PATH_TO_NEW_COPY
```

اسکریپت ابتدا ساختار CA1 را کنترل می‌کند، سپس یک کپی می‌سازد؛ فایل اصلی شما را دست نمی‌زند و پوشهٔ خروجی موجود را بازنویسی نمی‌کند. تمام RTLهای غیرهدف باید بایت‌به‌بایت با مبدا یکسان بمانند؛ نتیجه در `overlay_manifest.json` نوشته می‌شود. در فهرست سورس جدیدِ آن کپی از `rtl/files.f` استفاده کنید.

محدودیت‌ها:

- دو واحد حسابی از قرارداد CA2 و truncate استفاده می‌کنند؛ goldenهای قدیمی RNE، نتیجهٔ مرجع این نسخه نیستند.
- بافر سازگار، تمام فراداده را ذخیره می‌کند و ۴۴۹۹ گیت هزینه دارد. شمارش ۳۵۳۹ مربوط به بافر **بدون فراداده** است و برای این نسخه قابل استفاده نیست.
- اتصال top کامل CA1 با این سه جایگزین در محیط تحویل compile/elaborate شده است؛ گزارش در `results/ca1_integration.json` است. صحت عددی inference کامل شبکه در این فاز ادعا نشده است.
- بافر جدید ترتیب داده، full/empty، bank_select و رفتار قانونی handshake را در ۷ پیکربندی با نسخهٔ قبلی مقایسه می‌کند. مقادیر `rd_data` در زمانی که `rd_valid=0` معتبر نیستند و ممکن است با مدل قدیمی متفاوت باشند.
