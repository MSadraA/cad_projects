# پاک‌سازی و مهاجرت فایل‌ها

حذف‌ها از نسخه کاری جدید انجام شده‌اند. اسناد ورودی دو PDF حفظ شده‌اند و فایل ZIP ارسالی مبنای مقایسه بوده است.

| مورد نسخه ورودی | تصمیم و دلیل |
|---|---|
| `references/05_code_aggregate_REFERENCE_ONLY.txt` | کد تکراری و کهنه حذف شد؛ نسخه لازم تکلیف داخل submission با export از RTL جاری تولید می‌شود و در فهرست کامپایل اصلی نیست |
| `references/02_module_headers_ORIGINAL.v.txt` | header کهنه حذف شد؛ interfaces از RTL تولید می‌شود |
| `references/03_spec_v3_APPROVED_ORIGINAL.md` | به‌عنوان الزام جاری کنار گذاشته شد؛ اختلاف‌های مهم با PDF در traceability ثبت شده‌اند |
| `docs/05_plan.md` و plans تکراری و ناسازگار قدیم | یک برنامه کلی و پلن‌های جاری جایگزین شدند؛ هنگام export فقط نسخه مورد نیاز تجمیع می‌شود |
| `RTL_SHA256_SOURCE_MATCH.txt` | ادعای «عدم تغییر RTL» دیگر درست نبود؛ با گزارش و هش نسخه جاری جایگزین شد |
| `verification/results_all_11_icarus.txt` و گزارش قدیمی | لاگ ۶۳۶۷ سیکلی فقط برای مقایسه مبنا نگه داشته شده؛ نتایج جاری جدا و مشخص‌اند |
| چهار فایل مدل تکراری در ۱۱ case | پس از تأیید SHA-256 یکسان، ۴۰ کپی زائد حذف و چهار فایل مشترک در data/model نگه داشته شد |
| ۱۱ expected_logits و ۱۱ expected_digit قدیمی | یک JSON با نام صریح legacy_bias_first ایجاد شد؛ فقط برای بررسی مهاجرت استفاده می‌شود، oracle طراحی جدید نیست |
| true_labelهای تکراری با نام case | به metadata همان case در JSON منتقل شد |
| shell/doهای قدیمی با نام‌های 10/11 ناسازگار | runner واحد برای regression جایگزین شد؛ فایل جاری `run_modelsim.do` مسیر مستقل GUI با همین TB و RTL است |
| TBهای وابسته به اعداد و نام‌های داخلی قدیم | TB اصلی taskمحور و واحدهای فعلی جایگزین شدند |
| اسکریپت Python موجود | داخل ZIP اولیه هیچ فایل .py وجود نداشت؛ ابزارهای فعلی جدید و با قرارداد جاری ساخته شدند |
| باینری، cache، work، waveform و داده packed | جزو بسته منبع نیستند؛ در build بازتولید می‌شوند |

فایل‌های scalar ورودی و PNGهای موجود caseها بدون تغییر بایت حفظ شده‌اند. برای مرجع موجود، منشأ رسمی بیرون از ZIP مستقلاً تأیید نشده است؛ ادعای گزارش قدیمی درباره برابری با ZIP استاد، جای مقایسه مستقیم را نمی‌گیرد. manifest جاری صرفاً هویت بایت‌های فایل‌های ارسالی و مهاجرت آن‌ها را ثبت می‌کند.
