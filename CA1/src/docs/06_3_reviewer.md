# بازبینی پیاده‌سازی جاری با برنامه

این گزارش نتیجه بازبینی همین بازآرایی است؛ به مدل، گفت‌وگو یا تأیید استاد مستقلی نسبت داده نمی‌شود. پلن اولیه و اصلاح تقدم PDFها در `05_plan.md` ثبت شده و برنامه ماژول‌ها با نسخه نهایی همگام شده است.

| مورد بررسی | نتیجه |
|---|---|
| مرز Top | ده پارامتر عمومی، همگی از TB تا زیرماژول مربوط منتقل می‌شوند |
| تعداد منابع حساب | در منبع و hierarchy کامپایل‌شده Icarus دقیقاً یک ADD و یک MUL FP16 |
| مرز کنترل | FSM سراسری در Controller؛ تقویم و هندشیک محلی در Scheduler؛ آدرس فقط در AddressGenerator |
| Hardcodeهای وابسته به شکل شبکه | ابعاد، آدرس پایه FC2، تعداد ردیف‌ها، tailها، عرض متادیتا، RF و Argmax مشتق شده‌اند |
| فایل‌های ROM | هر پنج مسیر در Top و TB پارامترند؛ آزمون تغییر نام و پوشه و فاصله در نام پاس شده است |
| ترتیب بایاس | فقط bias-last مطابق PDF؛ مسیر bias-first و preload قبل محصولات حذف شده است |
| Ping-Pong | دو بانک، خواندن sealed، جلوگیری از overwrite، داده و tag همراه هم |
| رجیسترهای Pipeline | reset اعتبارها در آغاز اجرا؛ محصول الاستیک و جایگزینی هم‌لبه RowStage |
| حالت پایانی FC2 | padding وارد حساب نمی‌شود؛ گروه کوتاه seal و تخلیه می‌شود |
| RF مشترک | عمق رسمی ۱۰؛ بازنویسی پس از آخرین خواندن hidden و تکمیل تمام مقصدها |
| خروجی و پروتکل | Argmax متوازن، DONE یک‌سیکل، stable idle outputs، ignore busy start |
| Plan و Step | برای هر یک از ۱۷ ماژول Step و برنامه متناظر وجود دارد و با ابزار تولید/بررسی همگام‌اند |
| زبان و syntax | کامپایل Verilog-2005؛ lint هفت پیکربندی با هشدارهای مؤثر فعال |
| اعلان عرض پورت‌ها | پس از لاگ ModelSim 2020.1، اعلان ۹ ماژول اصلاح شد؛ ثابت مشتق پیش از پورت و کنترل این ترتیب در audit |
| صحت عددی | مرجع مستقل با حساب FP16 بعد از هر عمل؛ تمام hidden/logitها مقایسه می‌شوند |
| خروجی تجمیعی تسک۵ | از منابع یکتا ساخته شد؛ کد آن جدا کامپایل و یک inference موفق اجرا شد |
| اجرای ارائه در GUI | پارامترهای TB، حالت بدون golden، حالت مقایسه عددی صریح، DO مستقل از Python و موج‌های گروه‌بندی‌شده؛ مسیرهای موج با RTL بررسی می‌شوند |

تغییرات آگاهانه نسبت به پلن نخست، خواندن بانک کامل و بایاس انتهایی‌اند که پس از تصریح کاربر درباره تقدم صورت پروژه اعمال شدند. تقویم ردیف ناقص نیز با مشاهده شکست تست ابعاد کوچک اصلاح شد؛ عرض pointer خانه با عرض شمارنده ظرفیت تفکیک شد تا حالت‌های توان دو هم صحیح بمانند.

هیچ ماژول RTL بلااستفاده یا تعریف تکراری در فهرست کامپایل اصلی نیست. پورت‌های قدیمی بلااستفاده مانند layer_sel تکراری، init/preload و flush تکراری حذف شده‌اند؛ مدارک رابط جدید، قرارداد فعلی‌اند. ثابت‌های عددی IEEE، کدگذاری state و نوع دو نمونه حافظه عمداً پارامتر کاربری نشده‌اند.

در اصلاح سازگاری، نام، ترتیب، جهت و عرض پورت‌های هر ۱۷ ماژول با نسخه پیش از اصلاح مقایسه شد و برابر ماند. منطق اجرایی ۹ فایل اصلاح‌شده نیز پس از کنارگذاشتن اعلان‌های رابط و توضیحات، در سطح token برابر است. خروجی header تسک۲ فقط ثابت‌های لازم در محدوده ماژول را شامل می‌شود؛ ثابت داخل generate به محدوده بیرونی منتقل نمی‌شود.

محدوده باقی‌مانده تأیید: اجرای واقعی ModelSim/Questa، سنتز و STA/FPGA انجام نشده است. lint یا شمارش hierarchy جای شمارش منابع پس از سنتز را نمی‌گیرد. سوابق لازم برای پرامپت قبل/بعد تسک۴ و گفت‌وگوهای جداگانه تسک۶ در ورودی نبودند.
